<h1>Programadores para la Paz - Isabella López</h1>

<p>Este repositorio contiene las actividades desarrolladas durante el programa <strong>Programadores para la Paz</strong>. El trabajo está organizado por semanas y muestra el proceso de aprendizaje en el uso de la terminal, GitHub, Node.js, Express, JSON, Linux, seguridad digital, gestión de proyectos y servidores. El objetivo del repositorio es dejar evidencia de las prácticas realizadas y mostrar el avance en la creación de pequeños servicios relacionados con plataformas comunitarias.</p>
