# Programadores para la Paz

Bienvenido a mi repositorio de actividades para el programa Programadores para la Paz. En este espacio se encuentra organizada la estructura de archivos, talleres y reflexiones desarrolladas a lo largo del módulo de herramientas técnicas y control de versiones.

## Estructura del Repositorio

El proyecto se encuentra organizado por carpetas semanales para facilitar su navegación:

Semana 1: Contiene las actividades introductorias, el algoritmo propuesto y las primeras reflexiones teóricas.
Semana 2:Contiene las respuestas de selección múltiple, el registro de comandos de la terminal y la reflexión sobre la gestión de archivos.
