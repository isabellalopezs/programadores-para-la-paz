# Programadores para la Paz - Isabella López

Este repositorio contiene las actividades desarrolladas durante el programa Programadores para la Paz. El trabajo está organizado por semanas y muestra el proceso de aprendizaje en el uso de la terminal, GitHub, Node.js, Express, JSON, Linux, seguridad digital y servidores.

El objetivo del repositorio es dejar evidencia de las prácticas realizadas y mostrar el avance en la creación de pequeños servicios relacionados con plataformas comunitarias.

---

## Herramientas utilizadas

Durante el programa he utilizado las siguientes herramientas:

* Terminal de GitHub Codespaces.
* Git y GitHub para guardar y publicar avances.
* Node.js para ejecutar JavaScript desde el servidor.
* Express para crear servidores y rutas.
* JSON para organizar e intercambiar información.
* Comandos básicos de Linux.
* Buenas prácticas de seguridad digital.

Algunos comandos usados durante el proceso han sido:

```bash
git status
git add .
git commit -m "mensaje"
git push
mkdir
touch
cd
ls
cat
echo
uname -a
whoami
node server.js
```

## Semana 8

En esta semana se trabajaron temas relacionados con Linux, terminal, código abierto y seguridad digital. La actividad se enfocó en comprender la importancia de proteger plataformas comunitarias, cuidar credenciales y aplicar buenas prácticas de seguridad.

* preguntas-semana8.txt
* sistema.txt
* seguridad-plataformas.txt
* reflexion-semana8.txt
* seguridad/buenas-practicas.txt

Buenas prácticas incluidas:

* Usar contraseñas diferenciadas, combinando texto, números y caracteres especiales.
* Activar doble verificación para proteger mejor el acceso a las cuentas.
* Actualizar periódicamente el software para reducir riesgos de seguridad.

## Semana 9

En esta semana se trabajó el tema de servidores, estabilidad, puertos, logs y continuidad operativa. La actividad permitió comprender que una aplicación no solo debe funcionar en pruebas, sino también mantenerse estable y segura cuando se ejecuta como servicio.

Rutas trabajadas:

* /
* /estado

Archivos principales:

* server.js
* preguntas-semana9.txt
* ejecucion-servidor.txt
* componentes-servidor.txt
* reflexion-semana9.txt
* package.json
* package-lock.json

La ruta principal muestra el mensaje:

```txt
Servidor activo y funcionando
```

La ruta /estado devuelve una respuesta en formato JSON indicando que el servidor está funcionando.

## Aprendizajes principales

Durante el desarrollo de estas actividades he aprendido a crear carpetas y archivos desde la terminal, usar GitHub para guardar avances, crear servidores con Node.js y Express, trabajar con JSON, usar rutas GET y POST, organizar reportes comunitarios, aplicar buenas prácticas básicas de seguridad digital y comprender la importancia de la estabilidad de un servidor.

También he comprendido que la programación puede apoyar procesos comunitarios, mejorar la comunicación, organizar información, proteger datos y fortalecer la participación de las personas.
