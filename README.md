# 🕊️ Programadores para la Paz - Isabella López

Repositorio de actividades prácticas y desarrollo del programa. Todo el código ha sido gestionado mediante control de versiones y estructurado de forma limpia y profesional.

---

## 🛠️ Herramientas y Comandos Dominados (Semanas 1 - 3)
* **Navegación por Terminal:** Uso de la consola para moverse entre directorios (`cd`), creación de archivos (`touch`), carpetas (`mkdir`), eliminación (`rm`) y solución de rutas de entorno.
* **Control de Versiones (Git):** Flujo de trabajo completo para registrar cambios localmente y subirlos a la nube:
  * `git status`, `git add .`, `git commit -m ""` y `git push origin main`.

---

## 🚀 Proyecto Desarrollado: Semana 4 (Backend Básico)
Estructura inicial de un servidor backend utilizando Node.js.
* **`Semana 4/server.js`:** Servidor base configurado con JavaScript y Node.js escuchando peticiones en el puerto 3000.
* **`Semana 4/package.json`:** Manifiesto inicial de dependencias del proyecto.

---

## ⚡ Proyecto Desarrollado: Semana 5 (Servidor con Múltiples Rutas)

En esta unidad se avanzó en la construcción del backend, escalando el servidor inicial para gestionar diferentes puntos de acceso (endpoints) y procesar datos entrantes. El proyecto está ubicado en la carpeta `Semana 5` y contiene los siguientes componentes reales:

### 📁 Archivos creados en el repositorio:
* **`server.js`:** Servidor HTTP desarrollado con **Express** que implementa múltiples rutas de acceso (`GET` para consultar información estructurada y `POST` para recibir y procesar datos de formularios de forma segura).
* **`package.json` & `package-lock.json`:** Configuración del entorno de Node.js donde se registra formalmente la instalación del framework Express como dependencia del proyecto.
* **`.gitignore`:** Archivo de exclusión configurado para evitar que la carpeta pesada `node_modules/` sea cargada a GitHub, manteniendo el repositorio optimizado.
* **`conceptos-api.txt` & `pruebas.txt`:** Documentación técnica obligatoria con las respuestas del cuestionario y el registro de pruebas de las rutas implementadas.
* **`reflexion-semana5.txt`:** Análisis sobre el impacto de la organización de APIs para la transmisión clara y ordenada de la información comunitaria.
